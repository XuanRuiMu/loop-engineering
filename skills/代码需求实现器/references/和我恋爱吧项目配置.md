# 和我恋爱吧项目配置

## 基本信息

- **项目名**：和我恋爱吧
- **项目路径**：当前工作区内的 `和我恋爱吧`；启动时验证目录存在，不存在则停止并返回待确认
- **前端**：Vue 3 + Vite + TypeScript（端口5173）
- **后端**：Express + TypeScript（端口3000）
- **数据库**：MySQL

## 目录结构

| 类型       | 路径                          |
| ---------- | ----------------------------- |
| 前端源码   | `frontend/src/`               |
| 后端源码   | `backend/src/`                |
| 前端测试   | `frontend/e2e/`（Playwright） |
| 后端测试   | 项目内Jest配置                |
| 数据库迁移 | `database/`                   |

## 构建命令

| 操作     | 命令                           |
| -------- | ------------------------------ |
| 前端开发 | `cd frontend && npm run dev`   |
| 后端开发 | `cd backend && npm run dev`    |
| 前端构建 | `cd frontend && npm run build` |
| 后端构建 | `cd backend && npm run build`  |

## 测试框架

- 后端：Jest + Supertest
- 前端：Vitest + Vue Test Utils
- E2E：Playwright（`frontend/e2e/`）

## 编码规范

- 日志工具：`backend/src/utils/logger.ts`（riZhi模块，中文命名）
- 所有关键操作必须记录日志
- 翻译文件优先
- 零硬编码

## 开发验证注意事项

### 浏览器自动化验证规则

- 使用宿主当前可用的浏览器自动化能力打开页面、截图并检查实际界面。
- 不能仅依赖热更新或终端命令的布局数据判断界面已生效。
- 模型能够读图时执行视觉复核；不能读图时以DOM、布局、溢出和控制台证据替代，并在遗留中说明。
- 页面未变化时先确认开发服务实际端口和进程，再按项目脚本重启；不得假定固定端口。
- 自动化能力不可用时返回环境限制，不把未执行验证写成通过。

### Docker生产环境部署规则

- 生产环境属于高危外部写操作，部署前必须用通俗语言说明影响和回退方式并取得用户确认。
- Headless Worker不得直接部署；只返回部署待确认项，由主代理取得决定后执行。
- 确认后按项目实际编排文件执行构建和重启，并验证实际服务状态。
- 不在配置中硬编码机器路径、容器名或端口；启动时从项目实际配置读取。
- 用户未确认时，本地构建和测试仍必须完成，部署项进入遗留。
