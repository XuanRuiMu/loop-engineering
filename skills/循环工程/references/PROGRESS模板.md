# PROGRESS.md 模板

`PROGRESS.md` 是可覆盖的当前快照，不是日志。完成项立即删除，过期信息立即替换或删除；正常任务建议控制在40至70行。

## 运行时模板

```markdown
# 循环工程进度

状态：进行中
开始：YYYY-MM-DD HH:MM
更新：YYYY-MM-DD HH:MM
基线：<版本控制短哈希+证据路径|无>
目标：<一句话可验证结果>
停止：<机器可验证条件>
下一步：<动作；目标ID或代理实例>
边界：做=<范围>；不做=<排除项>；禁触=<禁止范围>
用户WIP：<当前受保护路径；无则写“无”>
常量变更：<无或旧值到新值；理由；授权>
已完成ID：<本轮已完成ID，逗号分隔；无则写“无”>

## 预算

|指标|上限|当前|
|---|---:|---:|
|总循环|30|0|
|子代理实例|30|0|
|主代理补位|3|0|
|墙钟/min|120|0|

## 功能点

|ID|目标与验收|依赖|状态/实例|修复/stall/轮次|树/证据|下一步|
|---|---|---|---|---|---|---|
|FP-01|<简述；机器验收>|无|待开始/无|0/0/估算=<n>|无|派发|

## 契约增量

|来源|类型|旧值到新值|未吸收消费者|
|---|---|---|---|
|FP-01|接口|<旧值>到<新值>|FP-02|

## 未决事项

|ID|状态/类型|原因与证据|下一步|
|---|---|---|---|
|FP-02|阻塞/环境|<短原因；命令或证据路径>|重跑门禁|

并发：代理=<实例或无>；门禁=<持有者或无>；其他写入=<写者或无>
```

没有契约增量、未决事项或并发写入时，删除对应空节和“并发”行，不保留空标题。

## 状态

### 全局状态

|状态|含义|允许进入|
|---|---|---|
|进行中|仍有可推进工作|完成、阻塞、待确认、熔断|
|待确认|需要用户决定|进行中、阻塞|
|阻塞|当前无法继续但仍保留未决事项|进行中、待确认|
|熔断|预算达到上限|待确认|
|完成|无待开始或进行中功能点，所有代理已结束，遗留已明确|新任务重新初始化|

### 功能点状态

|状态|含义|处理|
|---|---|---|
|待开始|尚未派发|选择依赖满足项派发|
|进行中|代理或主代理正在处理|继续、补位、阻塞或待确认|
|待用户确认|需要用户决定|批准后重新核验；拒绝后删除或转阻塞|
|阻塞|环境、依赖、方向、逻辑或权限阻塞|条件解除后重新核验|
|跳过|用户明确决定不再执行|直接删除功能点行，交付时列为遗留|
|完成|验收、证据和审查均通过|立即删除功能点行|

“阻塞”和“跳过”不是静默完成；必须保留原因、证据或可复现命令、影响和下一步。

## 计数口径

- 总循环：主代理完成一轮编排时加1；同一波并行仍只加1。
- 子代理实例：每个实际创建的独立代理加1，包含重派和嵌套审查代理；主代理补位不计。
- 主代理补位：主代理接手一个新的功能点时加1。
- 修复：真实失败后的实际修复尝试；与stall互斥。
- stall：空摘要、无验收推进、重复索要已有决定、收尾未完成；与修复互斥。
- 墙钟：从首次开始到当前恢复，不因会话恢复重置。

## 压缩规则

1. 每次更新直接重写当前快照，禁止追加旧记录。
2. 功能点完成后立即从功能点表删除，并把ID追加到“已完成ID”；最终交付后整行清空。
3. “已完成ID”只用于防止恢复时重复实现，不保存描述、证据或历史。
4. 用户明确跳过时直接删除功能点行，不写常驻未决项；交付时作为遗留说明。
5. 只保留待开始、进行中和当前未决事项；失效证据和决定立即删除，存活实例不得删除。
6. 同一ID只保留一个权威行；解决后的未决事项直接删除，不归档。
7. 契约增量只保留尚未被消费者吸收的行；完成、跳过或不再需要时立即删除。
8. 用户WIP只保留当前受保护路径；用户提交或撤销后立即替换或删除。
9. 基线必须指向真实证据文件，文件内保存文件清单和哈希；没有版本控制时也不得只写数量。
10. 证据只保留一个链接或一条可复现机器命令，禁止复制日志正文和完整改动清单。
11. 计数只保留一个来源；除新任务外不得回退或重置。
12. 禁止写入循环历史、完整代码、完整日志、详细设计、详细决策过程和已失效规则。
13. 可选节为空时整节删除；不得为了达到行数范围而填充内容。
14. 正常快照超过70行视为不合格，必须先删除过期或重复信息。
15. 每次写回后检查：行数、重复ID、失效引用、计数、存活实例和下一步。
16. 任何无法确认归属的文件都按用户WIP处理，不得自动清理。

## 状态转换

```text
待开始 -> 进行中
进行中 -> 完成 -> 删除功能点行并记录ID
进行中 -> 阻塞
进行中 -> 待用户确认
待用户确认 -> 进行中
待用户确认 -> 阻塞或跳过
阻塞 -> 待开始
待开始 -> 跳过
```

恢复不是独立状态。恢复时先重新核验基线、实际文件和活跃实例，再写入上述合法状态之一。
